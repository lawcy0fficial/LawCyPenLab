PostMessage Origin Confusion

CWE-346 · No origin validation · Attacker iframe reads sensitive posted data
This parent frame posts crew session data to a child iframe via window.postMessage(). The child does not check event.origin — any frame (including the attacker's) can receive the data. The Attacker Frame tab shows the captured secrets.
Fix: Always validate event.origin === "https://trusted.example.com" in the message event handler. Never use targetOrigin: "*" with sensitive data.
