Why normalisation order matters

  

    

      
VULNERABLE — WAF checks BEFORE decode

      

        1. Request arrives: GET /%61dmin HTTP/1.1

        2. WAF checks: /%61dmin ≠ /admin → ALLOWED

        3. Back-end decodes: %61 → a → /admin

        4. Back-end serves: ADMIN PAGE
      

    

    

      
SAFE — WAF checks AFTER normalise

      

        1. Request arrives: GET /%61dmin HTTP/1.1

        2. WAF decodes: %61 → a → /admin

        3. WAF checks: /admin = /admin → BLOCKED

        4. Attacker receives: 403
