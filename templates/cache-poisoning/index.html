X-Forwarded-Host Poisoning

The API endpoint reflects X-Forwarded-Host into response URLs but this header is not part of the cache key. First send a poisoned request, then send a clean one — both return the poisoned URLs.

UNKEYEDX-Forwarded-Host: evil.example
UNKEYEDX-Forwarded-Proto: https
