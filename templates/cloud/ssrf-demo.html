SSRF → Cloud Metadata Service (AWS IMDS)

CWE-918 · Server-side request to attacker-controlled URL · Reaches the instance metadata service
The server fetches whatever URL you supply and returns the response. On a real AWS instance, port 80 at 169.254.169.254 is the Instance Metadata Service (IMDS) — reachable only from the instance itself, which is exactly what makes SSRF so dangerous here: a request the server makes on your behalf can reach it even though you never could directly. This lab simulates IMDS locally so the same chain works without a real cloud instance.
IMDS targets (simulation on localhost:5000):
  • http://127.0.0.1:5000/latest/meta-data/
  • http://127.0.0.1:5000/latest/meta-data/iam/security-credentials/aegis-station-role
  • http://127.0.0.1:5000/instructor/status?key=INST-RESET-2024
  • http://127.0.0.1:5000/backup.sql
Real-world target: http://169.254.169.254/latest/meta-data/iam/security-credentials/<role> → temporary IAM access keys.
