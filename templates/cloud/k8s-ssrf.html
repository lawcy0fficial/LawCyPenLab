Kubernetes Internal API SSRF

CWE-918 · SSRF to http://kubernetes.default.svc/ · Reads secrets, tokens, configmaps
In a real Kubernetes deployment, every pod can reach the K8s API server at http://kubernetes.default.svc/. SSRF from the web container lets an attacker enumerate namespaces, read Secrets (DB passwords, JWT keys), list ServiceAccounts, and potentially escalate to full cluster control.
K8s API targets (simulation on localhost:5000/k8s-api/):
  • http://127.0.0.1:5000/k8s-api/api/v1/namespaces
  • http://127.0.0.1:5000/k8s-api/api/v1/namespaces/aegis-prod/secrets
  • http://127.0.0.1:5000/k8s-api/api/v1/namespaces/aegis-prod/configmaps
  • http://127.0.0.1:5000/k8s-api/api/v1/nodes
Real chain: SSRF → kubernetes.default.svc → /api/v1/namespaces/kube-system/secrets → admin SA token
