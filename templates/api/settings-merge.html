Deep Merge — Shared State Pollution

CWE-915 · Recursive merge on shared dict · No copy, no ownership check
The merge function recursively writes attacker-supplied JSON keys directly into the shared _USER_SETTINGS dict — no copy is made, no ownership checked. Any authenticated user can overwrite any other user's settings, or inject keys into the global dict.
Attack payloads:
  • {"admin": {"admin_menu": true}} — flip admin feature flag
  • {"admin": {"role": "commander"}} — overwrite role in shared settings
  • {"k.mbeki": {"notify": false, "theme": "hacked"}} — sabotage another user
Fix: import copy; user_settings = copy.deepcopy(_USER_SETTINGS[username]) — always merge into a per-user copy, never the shared object.
