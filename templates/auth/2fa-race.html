2FA TOCTOU Race Condition

CWE-362 · Check-then-act gap · Two concurrent requests with same OTP both succeed

The verify endpoint checks valid == True, sleeps 50ms (processing simulation), then sets valid = False. Two concurrent requests pass the check before either completes the invalidation — both get authenticated with the same OTP.
Distinct from the existing 2FA bypass (/auth/verify-otp) which exploits no-rate-limit + globally stored OTP. This is a TOCTOU race on the invalidation step itself.
