HTTP/2 Rapid Reset — CVE-2023-44487

HEADERS frame + immediate RST_STREAM · Bypasses flow control · 201M rps peak
Each HTTP/2 HEADERS frame triggers server-side stream processing. An immediate RST_STREAM cancels the response but not the work already done. With thousands of HEADERS+RST per second, the server exhausts CPU/memory while sending zero responses — completely invisible to standard rate limiters counting HTTP responses.

Real-world impact: Cloudflare, Google, and AWS all reported record-breaking DDoS attacks in 2023 using this technique before patches were deployed.
