SSRF Chain via Open Redirect Bypass

CWE-918 + CWE-601 · Allow-list bypassed via redirect from trusted host
The SSRF endpoint enforces an allow-list of trusted hostnames. But an allow-listed host (external.aegis-station.ops) has an open redirect at /go?url=<target>. The server follows redirects — so the attacker submits the trusted host's URL, which redirects to an internal target.

Remediation: Disable redirect following (allow_redirects=False), or re-validate the final URL after each redirect against the allow-list.
