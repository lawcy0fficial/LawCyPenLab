file:// SSRF — urllib Multi-Protocol

urllib.request.urlopen() accepts file://, ftp://, http:// — unlike requests

The requests library rejects file://. Python's urllib.request.urlopen() does not. A developer who switches from requests to urllib for "compatibility" silently opens local file read + FTP-bounce attack surface.
