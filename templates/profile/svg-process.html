SVG Upload — Server-Side XXE Processing

CWE-611 · lxml parses SVG to extract <title> metadata · External entity resolves file:///etc/passwd

The server parses uploaded SVG files with lxml (resolve_entities=True) to extract the <title> element for thumbnail metadata. An XXE payload in the title causes the parser to resolve file:///etc/passwd into the extracted text — bypassing upload filters that only check for <script> tags.
Distinct from the SVG XSS in /vrt/avatar (that's client-side; this is server-side).
