Insecure Randomness — Predictable Reset Token

CWE-338 · random.randint() seeded with time.time() · ±60s window = 120 seed candidates

Python's random module uses Mersenne Twister — a PRNG, not a CSPRNG. Seeding it with int(time.time()) (second-precision) limits the seed space to ~120 values within ±60 seconds of the request. The "Predict" action demonstrates the crack in real time.
Fix: Replace random.randint() with secrets.token_urlsafe(32).
