Open redirect bypass techniques · OAuth redirect_uri manipulation · HTTP parameter pollution

Open Redirect P2 · CWE-601

The /auth/redirect?next= endpoint checks that values don't start with http:// or https:// — but misses protocol-relative (//evil.example), backslash (\evil.example), and encoded variants.


    
CWE-601 · URL Redirection to Untrusted Site
Fix: allow-list of permitted redirect destinations

  


  
  

    
OAuth redirect_uri P2 · Unvalidated

    
The OAuth callback endpoint accepts any redirect_uri without checking it against a registered allow-list. An attacker steals the authorization code by supplying their own endpoint as the redirect destination.


    

      

        
        
      

    

    
    

    
CWE-601 · OAuth redirect_uri not validated against registered list
Impact: auth code / access token theft

  







  
HTTP Parameter Pollution P2 · CWE-235

  

    

      
The /api/v6/param-pollution endpoint uses request.args.get("role") for the auth check (returns first value) but business logic uses the last duplicate value — allowing auth bypass with ?role=crew&role=admin.

      

        
        
        
      

      

    

    

      
Why this works:

      
# Flask behaviour with duplicates:
# ?role=crew&role=admin

request.args.get("role")
# → "crew"  (first value, used for auth check)

request.args.getlist("role")[-1]
# → "admin" (last value, used for business logic)

# Auth check passes "crew" → not blocked
# Logic grants "admin" access → bypass

      
CWE-235 · Improper Handling of Extra Parameters
Impact: role escalation via duplicate params
